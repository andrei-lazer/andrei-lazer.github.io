Tunnels

Usecase: I am running a local http server on a remote machine, and I want to connect to it from my local browser.

Steps:

  1. Local: ssh -L <local-port>:localhost:<remote-port> maths-cpu (sets up a forward tunnel)
  2. Remote: python -m http.server -p <remote-port>
  3. Done! Connect to http://localhost:<local-port>/ from your local browser.
