aerc

aerc is a TUI email client.

Gmail setup

  1. in the password spot, put in an app password from here.
  2. use IMAP and SMTP
  3. go to ~/XDG_CONFIG_HOME/aerc/accounts.conf. at the end of the outgoing address, there's a port number. Remove it and the colon.
  4. add this to the end of the account:
default       = INBOX
folders-sort  = INBOX
postpone      = [Gmail]/Drafts
cache-headers = true

Keybinds/commands

  • use ? to see keybinds
  • :mv moves selected emails
  • v and V are used to select emails
